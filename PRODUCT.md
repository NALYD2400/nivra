# Product

## Platform
Windows desktop application.

## Stack
React and Tauri 2 with a Rust backend.

## Purpose
Give one person a compact view of their AI coding service quotas and reset times. Present unavailable and manually entered values honestly.

## Visual reference
Sprint: dark background, violet lighting, quiet sidebar, compact data-first layout. The window is smaller and adapted to account monitoring.

## Constraints
Codex, Claude Code, Cursor and Antigravity are requested. Integrations depend on each service's accessible, supported data. Do not imply that a manual account is connected.
